# LocalBuildManager TALUDE — R20.4

Gestor local dedicado ao branch `classify-las-r20-4-module`.

Arranque recomendado: duplo clique em `START_BUILD_MANAGER.bat` na raiz do repositório.

Funções:
- Verificar ambiente e ficheiros obrigatórios;
- TESTAR;
- BUILD;
- BUILD + TESTES;
- repetir a etapa falhada;
- parar pipeline;
- abrir a pasta `builds`;
- logs em tempo real.

O gestor usa `localbuild/talude_v1.json` como perfil autoritativo e funciona também numa pasta extraída de ZIP, sem GitHub Actions.

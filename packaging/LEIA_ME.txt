TALUDE STUDIO V1 - Windows Portable

OBJETIVO
  Extrair automaticamente linhas 3D de CRISTA e PE DE TALUDE.

INTERFACE
  Viewer 3D profissional baseado na shell Cloud_to_lines:
  - Potree LOD
  - EDL
  - RGB / Elevacao / Classificacao
  - filtro de classes
  - CRISTA e PE sobrepostos diretamente na nuvem

ARRANQUE
  Execute START_TALUDE_V1.bat

FLUXO
  1. Novo/Abrir projeto
  2. + Adicionar LAS / LAZ / COPC
  3. Escolher classes (por defeito: So Solo)
  4. DETETAR CRISTA + PE
  5. Rever as linhas na nuvem
  6. Abrir resultados para DXF / GeoJSON / CSV / debug

CORES
  Amarelo = CRISTA
  Ciano   = PE DE TALUDE

BUILD
  GitHub Actions nao sao necessarios.
  O build e executado localmente pelo Local Build Manager.
